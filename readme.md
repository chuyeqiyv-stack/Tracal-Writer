# 催客写作 Trecal

一款纯本地单机的中文小说写作软件，为网文作者打造：书架与章节管理、码字时速统计、成就勋章、起名助手、时间轴 / 地图 / 大纲设定、人物关系、历史版本与 WebDAV 同步——数据全部保存在你自己的电脑上。

**设计与开发：夜夜笙歌林夜歌 · AI 协作**

---

## v1.7.1 更新内容

> 新建章节的默认标题改为按目录里的最大编号续号，改名、删章后不再出现「重号 / 跳号」；正文标题行进入即全选，直接输入即可覆盖。

### 章节默认命名

- 「第 N 章」按**标题里的最大编号 +1** 生成：中间章被改名成「武松打虎」、末章被删除、番外插队等情况都不再影响续号。
- 识别中文数字、阿拉伯数字、全角数字与全角空格：`第十二章`、`第12章`、`第１２章`、`第 1 章` 都能正确解析。
- 新标题的数字写法跟随最后一章：末章是「第3章」就生成「第4章」，末章是「第三章」就生成「第四章」，识别不到时默认中文数字。
- 新建章节后默认标题直接进入行内编辑并**全选**，键入即覆盖，不用先手动删旧名。
- 分章目录式与旧单文件式两种书稿布局行为一致；该逻辑由模型层单测覆盖（13 项，含万级中文数字与混合写法）。

## v1.7.0 更新内容

> 存储改为「一章一文件 + 按需加载」：打开大书只读当前章，保存只写改动的那一章。数据目录结构与旧库双向兼容，首次打开自动迁移。

### 一章一文件

- 每章正文独立成 `books/<书籍id>/chapters/<章节id>.json`，保存时只写脏章节；manifest 只保留结构（章节 id / 标题 / 文件名），schema 升至 6。
- 每章的字数与更新时间移入 `chapter_index.json` + 追加日志：日常保存只追加一行，日志超过 64KB 才压缩成基文件，避免每次保存重写整份索引。
- 磁中断电留下的半截日志行自动忽略，前面的完整行照常生效；索引缺失时按章节文件自愈重建。

### 按需加载

- 打开书籍只加载目录结构，正文首次访问才读盘；写作页只保留**当前章 ±1**，切章后释放其余已读正文。
- 打开 2000 章 / 810 万字的书约 7ms，单次保存只写 1 个章节文件（约 12KB）+ manifest。
- 全书搜索、统计、重新统计字数都改为「一章一读、读完即释放」，不再把全书正文塞进内存。
- 旧的分片布局（32 章/片）只保留读取与迁移能力，首次打开自动升级为一章一文件。

### 设定分层与多元宇宙

- `library.json` 只保留书单；设定改为**一卡一文件**放在 `settings/` 下（角色 / 设定卡 / 大纲 / 时间线），另建轻量卡片索引负责列表与搜索，正文不进索引。
- 旧版 `library.json` 里的设定数据在首次启动时自动迁移到卡片目录：先写临时目录、逐项校验、全部成功才切换，失败保持原状；迁移可重入，重复启动不会重复搬。
- 卡片搜索走索引缓存，支持按类型过滤；标题与正文都能命中，保存卡片时增量更新缓存。
- 角色关系图升级为**多元宇宙**：角色库全局共用，连线与画布坐标按宇宙分别保存；可新建 / 重命名 / 删除宇宙，主宇宙不可删除，删除宇宙后角色回到「未分类」。

## v1.6.0 更新内容

> 存储层从「整本单文件」升级为「分章目录」：自动保存只写改动过的章节，顺带解决了大书保存慢与整份回写丢数据的隐患。旧单文件永久保留，老库原样可读。

### 分章存储

- 书籍目录 `books/<书籍id>/manifest.json` 记录书元数据与卷章顺序，章节正文按 32 章一片存进 `chapters/shard-xxxx.json`；保存时只写脏分片。
- 以 manifest 为唯一提交点：先写章节分片、再写 manifest、最后清理被移除的章节；中途中断不会读到半新半旧的目录。
- 旧单文件首次保存时自动迁移，原文件改名 `.migrated-<时间戳>` 永久留档；迁移中断留下的 `.mig-*` 临时目录在下次启动时自动清理。
- 退出时给分章格式的书落一份旧版可直接打开的单文件快照（`compat.bak`），没变化的书按签名跳过，不影响退出速度。

### 云端备份适配

- 同一本书只允许一种格式落盘（单文件或分章目录），不会两份并存；WebDAV 备份按此规则打包。
- 备份与恢复会跳过 `.mig-*` 等点开头的临时目录，避免把迁移残骸恢复成垃圾数据。
- 更换数据目录、上传备份、从云端恢复期间暂停自动保存，避免备份包里出现半新半旧的分片。

## v1.5.0 更新内容

> 导出能力补齐：章节目录右键「卷」可「导出本卷…」，书架右键书籍可「导出整本书…」，均支持 txt / docx，零依赖手写 OOXML。只读导出，不改正文、不动撤销栈、不触发保存与音效；数据目录、JSON 结构、文件名均不变，老库原样可读。
>
> 本版另增：灵感迁到书稿数据目录（与书稿、伏笔同处一个目录）；新增伏笔功能（正文右键添加伏笔 / 填坑，列表在目录侧栏「相关」页）。

### 灵感保存位置迁移

- 灵感从「软件根目录/灵感」迁到「书稿数据根/灵感」，与书稿、伏笔同处一个目录，备份只需一个目录。
- 迁移自动完成：旧位置的文件按 `(content, created_at)` 去重合并、按时间升序，源文件改名 `*.migrated-<时间戳>` 留档，不删除；重复启动不会重复合并。
- 迁移先读后写、写成功才留档，任何一步失败都保留原文件；数据目录不可写时回落到软件目录，并在灵感板顶部显示实际路径。
- 迁移后首次打开灵感板会有一句说明，并提供「打开目录」入口。

### 伏笔

- 正文中选中文字 → 右键「添加伏笔」：标题必填、说明可选，回车保存、Esc 取消。
- 正文中选中文字 → 右键「填坑」：列出本书所有未收伏笔，选一条即把当前选区记为收线点；可在列表右键「解除收线点」，解到 0 条自动回到未收。
- 伏笔列表在目录侧栏「相关」页下方：红点为未收、绿点为已收，显示标题、埋在哪章、收在哪章；顶部显示「还有 N 个坑没收」。
- 点击列表条目定位到埋点并选中原文；右键支持编辑、定位、解除收线点、删除。三条降级定位：按记录的起止位置比对 → 章节内搜索最近一处 → 提示「原文已改动，无法精确定位」并展示章节与原文片段。
- 章节删除后伏笔不删除，标注「锚点失效」，仍可查看与编辑。
- 分书存放：`书稿数据根/伏笔/<书名>.json`，作者口径与灵感一致；书名改动同步改名，失败保留旧名不丢数据。
- 伏笔不进正文、不算字数、不进撤销栈、不进入导出内容；写入沿用临时文件 + 原子替换、`.bak` 备份、损坏文件改名留档。

### 整卷导出

- 入口：章节目录右键「卷」标题 → 「导出本卷…」；只导出当前卷，不做整本导出；空卷时该项自动禁用并给出说明。
- 先选格式（txt / docx 单选），再弹保存对话框：默认文件名为卷名 + 扩展名，默认目录为上次导出目录（首次为系统文档目录）。
- 一卷一个文件，卷内章节按当前顺序合并；空章也导出，正文为空只保留章名。
- txt：UTF-8 带 BOM、CRLF 换行，章名前空一行、章后空一行、章与章之间空两行，双击记事本不乱码。
- docx：零依赖手写 OOXML（不引入 python-docx / lxml），章名使用标题样式并在章前分页，中文东亚字体取当前正文字体，首行缩进两字（`firstLineChars=200`），行距沿用当前排版倍数，默认 A4 页边距。
- 卷名与文件名中的非法字符、控制字符替换为下划线，超长名自动截断；同名文件沿用系统保存对话框的覆盖确认，不静默覆盖。
- 写盘走临时文件 + 原子替换，失败不留半截文件并弹中文提示；导出全程只读，不影响正文、撤销栈与自动保存。

### 整本导出（一章一个文件）

- 入口：书架书籍右键 → 「导出整本书…」；与分卷导出并存，共用同一套格式选择对话框与同一个零依赖写入器。
- 选择父目录后自动创建以书名命名的文件夹（非法字符替换为下划线）；一章一个文件平铺其中，不按卷建子文件夹。
- 全本按当前章节顺序连续编号：`001 章名.txt` / `001 章名.docx`，编号位数按总章数自适应（至少 3 位）。
- 空章同样导出，正文为空只保留章名；超长章名按 Windows 路径上限截断，同目录重名自动追加序号、不覆盖。
- 同名文件夹已存在时提示选择「合并到已有文件夹」或「新建带时间戳的文件夹」，不静默混写。
- 单章写盘失败会清理本次已写文件，并以中文提示已成功多少章、失败哪一章、原因是什么。

## v1.4.6 更新内容

> 第二档轻量化：动效统一按 60fps 上限推进，并在窗口不可见时停表。数据目录、JSON 结构、文件名均不变，老库原样可读；不改任何功能与视觉呈现。

### 动效

- 动画统一按 **60fps 上限** 推进：Qt 动画固定 16ms 一帧，QTimer 驱动的动画循环间隔不低于 17ms，不再跟屏幕刷新率跑。
- 窗口 **最小化 / 切到其它程序 / Hide** 时暂停全部动画（淡入淡出、卡片 hover / press、圆环、抽屉、粒子等）；恢复后从当前帧**原地续播**，不跳帧、不停在半路。
- 像素级比对：书架、正文、设置抽屉、淡入动画中点四处截图与 v1.4.5 完全一致，**视觉未变**。

### 章节历史

- 每次自动保存记录一个历史版本：按 10 分钟间隔或 200 字变化去重，手动保存（Ctrl+S）始终立即记录。
- 每章保留最近 5 个版本（成就可扩容），全书历史总量上限 40MB，超限按最旧淘汰。
- 历史面板可预览任意版本与当前正文的差异，还原前先给当前正文补一个保底快照，误还原也能找回。
- 历史文件独立存放，不进撤销栈、不改正文字数统计；删除章节或书籍时随库一并清理。

### 文本体检

- 规则覆盖「的 / 地 / 得」误用、重复字（的的 / 了了）、成对引号括号未闭合、中文里的半角标点等；可只扫当前章，也可全书扫描并按章节列出。

### 修复

- **数据安全：时间轴编辑丢失**（最重要）：根因是 `library.json` 整份全量回写、双进程/双窗口并发覆盖、防抖保存未在关闭时 flush、写入无原子性、读入规范化吞未知字段。现已改为：按数据目录的 QLockFile 单实例锁（崩溃 5 秒后自动接管，二次启动提示后退出）、同一时间轴复用单窗口、closeEvent 逐面板 `flush_pending()`、`tmp + fsync + os.replace` 原子写并保留 `.bak`、未知字段按 id 合并保留。复现脚本覆盖「A 写新 → B 关 → 新内容消失」与断电式 kill：修复前必现，修复后不复现。用户侧结论：**此前已经丢失的那一版无法恢复**，但现有数据不会再被旧进程覆盖；正文未受影响（丢的是时间轴这一批新增事件）。
- **封面 125%/150% 只显示左上角**：`drawPixmap` 源矩形误用 DIP 而 Qt 按设备像素解释，DPR 桶 1.5 时只画左上 2/3×2/3，裁掉右侧约 32%、底部约 33%（含整块书名）；改为完整设备像素后，内容区与原图 MAE 4.5、底部书名区 3.3（旧写法 53.6）。
- **封面上下被裁**：旧的填充式缩放会切掉上下约 4.2%，改为 contain 整图可见、左右留边对称。
- **跨 DPR 下半留白**：`drawPixmap` 以 QPointF 作目标点时尺寸错位，统一改矩形目标。
- 正文隐形滑块失效：接通的死开关与打字不触发两个根因均修掉。
- 调行间距后空文档提示文字显示不全。
- 起名助手切换分类时旧按钮残留未销毁。
- 时间轴事件名被固定单行框截断（含显式换行显示不全）。
- 成就模块中从未被调用的死代码已清理。
