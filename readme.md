# 催客写作 Trecal

一款纯本地单机的中文小说写作软件，为网文作者打造：书架管理、章节目录、码字时速统计、成就勋章、起名助手、时间轴 / 地图 / 大纲设定、历史版本与 WebDAV 同步，数据全部保存在你自己的电脑上。

---

## v1.1.0 更新内容

### 文件导入
- 书架空白处右键 →「导入文件…」，支持导入本软件（含历史版本）导出的同类型文件：
  - **小说 TXT**：自动识别书名、作者、分卷与章节，还原为完整书籍
  - **设定 TXT**：导入为一篇设定文档
  - **时间轴 / 大纲 JSON**：完整还原事件、节点与连线
  - **地图底图**：把导出的 PNG 等图片导入为新地图的底图，可继续标注

### 数据保存位置调整
- 默认数据目录改为 **`C:\Users\（用户名）\Documents\催客`**，字数统计、成就、设定、时间轴、地图等本体数据都在这里，查找与备份更方便
- 老用户升级后首次启动会**自动把旧目录数据迁移**到新位置（旧目录保留作为备份）；此前设置过自定义目录的用户不受影响

### 问题修复
- 修复调整行间距后，空文档的默认提示文字显示不全的问题

## v1.0.0 更新内容

### 起名助手大升级
- 分类从 2 类扩展为 **7 大类**：人物 / 地点 / 势力 / 装备 / 功法 / 怪兽 / 其他
- 每类配备**子类型筛选**：
  - 人物：不限 / 男 / 女（另支持中文 / 西方 / 日式风格，可指定姓氏与名字）
  - 地点：东方 / 西方 / 日式
  - 势力：正道 / 魔道 / 中立
  - 装备：武器 / 防具 / 饰品
  - 功法：剑诀 / 掌法 / 心法 / 身法
  - 怪兽：妖兽 / 灵兽 / 凶兽
  - 其他：丹药 / 称号 / 灵物
- 新增**「后缀」输入框**（选填），生成的名字自动拼接指定后缀
- 全新词库扩容（新增约 400 条词条），结果以 4 列胶囊墙展示，**点击即复制**
- 界面改为圆角卡片式，居中标题 + 右上关闭，按住空白处可拖动

### 问题修复
- 修复切换起名分类时旧按钮残留未销毁的问题
- 清理了成就模块中从未被调用的死代码

### 体积与速度优化
- 剔除未使用的组件、清理无引用的图片资源与冗余文件
- 图片资源无损观感压缩，安装包进一步缩小，启动加载更快
