# 催客写作 Trecal · 使用说明

版本 1.0.0 · Windows 桌面版

***

## 一、软件介绍

**催客写作（Trecal）** 是一款面向小说作者和文字爱好者的纯本地桌面写作软件。
它的设计目标是：**打开就能写，数据全在你自己的电脑里。**

- **纯本地单机**：不需要注册、不需要登录、不联网也能用，所有作品只保存在本机

- **界面清爽**：浅色 / 深色主题一键切换，支持自定义品牌主色调，左侧目录与右侧面板采用半透明水晶玻璃质感

- **为长篇而生**：书架、卷章目录、大纲思维导图、故事时间轴、世界地图、相关设定，一应俱全

- **激励写作**：码字时速统计、成就勋章系统，见证你的每一个坚持

## 三、主要功能

### 书架与作品管理

- 封面墙网格视图 / 紧凑列表视图，展示书名、作者、字数与最近更新

- 作品分组管理；删除的作品先进入回收站，可恢复或彻底删除

### 沉浸式编辑器

纯文本编辑，自动保存（输入停顿约 1.5 秒即存），`Ctrl+S` 随时手动保存

  成对标点自动补全：输入引号、括号自动配对；选中文字输入左引号可自动包裹

 写作主题：纯白 / 护眼绿 / 羊皮纸黄 / 星空蓝 / 纯黑，也可上传自定义背景图

  支持导入本地字体文件（.ttf），中西文字体分别设置

  智能排版：段首缩进、段间空行、标点规范化，一键整理当前章节或全书

 查找替换（`Ctrl+F`）与全书全局搜索（`Ctrl+Shift+F`）

### 码字时速面板

- 右侧实时显示：本次字数、码字速度（字/分 ↔ 字/时 拨动开关切换）、码字时长、空闲时长

- 停写 30 秒后开始记录空闲，重新打字即恢复计时，数据不清零

### 创作辅助

- **故事时间轴**：独立大窗口，可无限延伸的事件线，节点可命名、描述、拖动

- **大纲思维导图**：以卡片形式整理章节脉络

- **世界地图 / 相关设定**：地点、人物等设定资料集中管理

- **起名助手**：内置中文 / 西方 / 日式本地字库，一键生成名字，点击即复制

### 成就与统计

- 坚持写作可获得成就勋章（首次成书、连续坚持、字数里程碑等）

- 统计页汇总总字数、码字天数等写作数据

### 数据安全

- **历史版本**：自动保存与切章、排版前自动留快照，可在历史版本中预览并恢复

- **云同步（可选）**：支持坚果云 WebDAV 手动上传备份 / 恢复；不配置则完全无任何联网行为

### 快捷键

| 快捷键                 | 功能       |
| ------------------- | -------- |
| `Ctrl+S`            | 立即保存     |
| `Ctrl+F`            | 查找替换     |
| `Ctrl+Shift+F`      | 全局搜索     |
| `Ctrl+N`            | 新建章节     |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做  |
| `Esc`               | 关闭右侧设置面板 |

## 四、数据存储位置

你的全部作品保存在本机（默认 `%APPDATA%\MojiWriter`）：

- `library.json` —— 书架索引与分组

- `books\` —— 每本书的完整内容

- `history\` —— 章节历史快照

- `covers\` —— 封面与头像图片

- `settings.json` —— 偏好设置

**建议定期备份整个 MojiWriter 文件夹**（复制到U盘或网盘即可）。
卸载软件不会删除这些数据；想彻底清空时手动删除该文件夹。

## 五、常见问题

- **双击没反应 / 启动慢**：首次启动需要解压运行环境，请耐心等待数秒；个别杀毒软件可能误报，添加信任即可

- **换了电脑怎么迁移**：把 `%APPDATA%\MojiWriter` 整个文件夹拷到新电脑同一位置

- **字体怎么换**：编辑器工具栏打开字体面板，中文 / 西文分开设置，可导入本地 .ttf 字体

- **写错了能找回吗**：能。历史版本保留多个快照，打开「历史版本」选择时间点恢复
