## 一、版本概述
1.4.x 系列集中处理三类问题：一是界面层的交互阻断，二是写作手感与排版一致性，三是编辑控件的状态残留。本次发布的 1.4.2 为重要修复版本，建议所有 1.4.x 用户升级。

## 二、1.4.2 重要修复
正文无法点击、无法输入

现象：写作页正文区域点不进、打不出字，标题仍可正常编辑；重启程序、新建作品均无法恢复。

原因：清空正文页时对编辑控件执行了禁用操作，后续仅恢复外层页面。Qt 中父控件重新启用不会解除子控件自身的禁用状态，导致正文长期处于不可编辑状态。删除当前章节、删除作品、从云端恢复数据、清空工作区均会触发该路径，而清空动作在打开作品与打开章节时亦会执行，因此重启后问题重现。

修复：载入正文前主动解除异常锁定状态；在点击正文与获得焦点时进行状态自检，发现控件被禁用、被置为只读或布局被冻结时先复位再处理本次操作；主窗口激活时清理残留遮罩。同时修正关闭设置后焦点未归还正文的问题。自检开销约每次 2–3 微秒，不影响使用。

## 三、1.4.1 写作手感与排版
- 回车空行 ：移除将空段落压缩至 6 像素的旧机制，空行高度与正文行高一致，可连按回车产生多个空行。
- 空行高度不一致 ：空行与正文原分别采用绝对像素与比例行高，现统一为按字号派生的行高。
- 字号调整 ：改为只修改文档默认字体，不再将字体写入正文内容；每次应用均核对控件实际字号，避免被样式表覆盖。调整字号后滚动位置按比例保持，光标与选区不变。
- 行距设置 ：改为按字号派生行高写入所有段落，单行段落同样生效；多字号、多行距组合实测误差为 0。
- 导入字体 ：字体文件归档至数据目录并在启动时重新注册，导入后即时生效、重启后不丢失。
- 字体族切换 ：修正西文与中文字体双栈导致中文字体族不参与渲染的问题，改为单一字体族，切换后字形立即更新；全文重排耗时由约 118ms 降至约 62ms（9 万字）。
- 粘贴 ：改为纯文本粘贴，外部字体、字号、颜色不再带入正文。
- 自定义背景 ：由单张扩展为最多 5 张缩略框，长边压缩至 1920 像素，第 6 张会被拦截并提示；删除当前背景时自动回落到纯色纸张。
- 预设纸张色 ：按指定范围移除 9 项，保留 8 项；旧配置指向已移除的色值时自动回落，不报错。
- 制表符 ：新增「Tab 插入中文缩进」开关，插入两个全角空格，默认关闭。
- 空行段距 ：空行不再附带段前段后距与缩进。
- 撤销栈 ：排版类操作不再污染文字撤销记录。

### 修复

- **数据安全：时间轴编辑丢失**（最重要）：根因是 `library.json` 整份全量回写、双进程/双窗口并发覆盖、防抖保存未在关闭时 flush、写入无原子性、读入规范化吞未知字段。现已改为：按数据目录的 QLockFile 单实例锁（崩溃 5 秒后自动接管，二次启动提示后退出）、同一时间轴复用单窗口、closeEvent 逐面板 `flush_pending()`、`tmp + fsync + os.replace` 原子写并保留 `.bak`、未知字段按 id 合并保留。复现脚本覆盖「A 写新 → B 关 → 新内容消失」与断电式 kill：修复前必现，修复后不复现。用户侧结论：**此前已经丢失的那一版无法恢复**，但现有数据不会再被旧进程覆盖；正文未受影响（丢的是时间轴这一批新增事件）。

- **封面 125%/150% 只显示左上角**：`drawPixmap` 源矩形误用 DIP 而 Qt 按设备像素解释，DPR 桶 1.5 时只画左上 2/3×2/3，裁掉右侧约 32%、底部约 33%（含整块书名）；改为完整设备像素后，内容区与原图 MAE 4.5、底部书名区 3.3（旧写法 53.6）。

- **封面上下被裁**：旧的填充式缩放会切掉上下约 4.2%，改为 contain 整图可见、左右留边对称。

- **跨 DPR 下半留白**：`drawPixmap` 以 QPointF 作目标点时尺寸错位，统一改矩形目标。

- 正文隐形滑块失效：接通的死开关与打字不触发两个根因均修掉。

- 调行间距后空文档提示文字显示不全。

- 起名助手切换分类时旧按钮残留未销毁。

- 时间轴事件名被固定单行框截断（含显式换行显示不全）。

- 成就模块中从未被调用的死代码已清理。

- **同一数据目录不能同时开两个实例**：第二次启动会提示并退出；这是为了避免两个进程共用 `library.json` 互相覆盖。

# 催客写作 Trecal · 纯本地小说写作软件（v1.0.0）

一款面向 Windows 的桌面小说写作工具，采用极简扁平的新版界面：

- **书架主页**：左侧导航栏（首页 / 发现 / 回收站 / 分组 / 用户卡片）+ 右侧书籍封面墙
- **编辑器**：上图下字的顶部工具栏 + 目录树侧边栏 + 沉浸式写作区
- **右侧**：可滑出的「更多设置」抽屉（含深浅色、独立配色、云同步）

技术栈：**Python 3.11 + PySide6**，数据全部保存在**本地 JSON 文件**中。
**默认纯本地单机；可选的坚果云 WebDAV 同步完全由用户手动触发。**

## 一、快速开始

```bash
# 1. 安装依赖（建议在虚拟环境中执行）
pip install -r requirements.txt

# 2. 启动
python main.py
```

首次启动会自动创建一本示例书《星落长夜》（含「楔子 / 第一章 / 第二章 / 结局」），
方便直接体验完整目录与字数统计。

## 三、功能清单

### 全局界面

- **极简纯白默认主题**：主区域 `#FFFFFF`、侧边栏 `#F5F5F5`，按钮 / 输入框统一 6px 圆角 + 极淡边框
- **深色 / 浅色一键切换**（深色 `#1E1E1E`），界面实时刷新，选择自动保存
- **独立配色**：在设置中可分别自定义工具栏、状态栏、写作区的背景与文字颜色（留空跟随主题）
- **顶部工具栏「上图下字」**：图标在上、文字在下，悬停有浅灰圆角背景与轻微放大动画

### 书架主页

- **左侧导航**：首页 / 发现 / 回收站，分组列表，底部用户头像与昵称（点击可修改）
- **网格视图**：3:4 封面卡片 + 绿色「新作品」角标（创建 7 天内）+ 悬浮阴影；无封面时显示渐变底纹
- **列表视图**：紧凑行展示封面缩略图、作者、章节、字数与日期
- **卡片信息**：书名、作者、最近更新章节与正文摘要
- **右键菜单**（卡片或空白处）：新建作品、新建分组、打开、重命名、移动到分组、移入回收站 / 恢复 / 彻底删除

### 新建作品弹窗

- 书名、作者、标签**全部默认空白**（仅占位符提示）
- **真实封面选择**：点击虚线框弹出文件选择器，选图后即时预览缩略图，保存后展示在书架

### 码字编辑器

- **字体管理**：中文 / 西文字体分别选择（QFontComboBox），支持**导入本地 .ttf 字体**，
  导入后记住路径，下次启动自动加载
- **写作主题面板**：圆形预设色块——跟随主题、纯白、护眼绿、羊皮纸黄、星空蓝、纯黑，
  点击实时切换写作区背景；支持**上传自定义图片**作为写作区背景
- 纯文本输入，自动成对标点，1.5 秒自动保存
- 底部状态栏：光标行列、本章字数、全书字数、自动保存时间
- 右下角浮动「置顶 / 置底」按钮，右侧可显示快速滚动滑块（均可在设置中关闭）

### 故事时间轴（硬核功能）

- 顶部工具栏「时间轴」按钮打开**独立大窗口**（1280×760）
- 一条可向右无限延伸的绿色主横线，**按住空白处拖拽**即可滑动
- **刻度间隔可切换**：天 / 月 / 年
- **点击横线**新增事件节点，节点上下可命名并填写描述
- **节点可拖动**沿横线调整位置；所有节点数据**持久化保存到当前书籍**中

### 起名助手（完全重写）

- **左右分栏**：左侧 40% 筛选区——人物 / 地点页签、中文 / 西方 / 日式类型、
  性别筛选、指定姓氏 / 名字输入框；右侧 60% 结果区
- 点击底部绿色「生成」按钮，从**本地字库字典**随机生成 **21 个（7 行 × 3 列）不重复名字**
- **点击任意名字即复制到剪贴板**，并弹出「已复制」轻提示

### 坚果云 WebDAV 手动同步（可选）

- 设置抽屉新增「云同步」页：WebDAV 地址（默认 `https://dav.jianguoyun.com/dav/`）、
  账号、密码（坚果云请使用「应用密码」）
- **上传备份到云端**：把本地全部 JSON 数据打包为 zip 上传
- **从云端恢复数据**：拉取云端备份并覆盖本地数据
- 后台线程执行，完成后弹窗提示成功 / 失败；**不开启则完全无联网行为**

### 其他核心功能

- **智能排版**：按当前排版设置重排当前章节或全书（重排前自动保存旧稿快照）
- **历史版本**：每 8 分钟、切换章节、排版 / 替换前自动保存快照，每章最多 20 个，可预览并恢复
- **查找替换**：支持「当前章节」与「全书」范围，可区分大小写
- **全局搜索**：跨章节搜索，结果带章节名与行号，双击定位并高亮
- **字数统计 / 码字时速**：独立面板查看，时速连续两分钟无输入会暂停计时

## 四、本地数据位置

默认目录：`%APPDATA%\MojiWriter`

```
%APPDATA%\MojiWriter\
├─ library.json                        # 书架索引（含分组、回收站状态）
├─ settings.json                       # 全局设置（主题、字体、云同步配置等）
├─ covers\                             # 书籍封面与头像图片
├─ books\<book_id>.json                # 单本书的完整内容（含时间轴节点）
└─ history\<book_id>\<chapter_id>\     # 章节历史快照
```

- 可通过环境变量 `MOJI_DATA_DIR` 指定其他数据目录（便于便携使用或测试）。
- 写入采用「临时文件 + 原子替换」，降低异常退出时文件损坏的风险。
- 卸载软件不会删除上述数据，手动删除该目录即可彻底清空。

```bash
# 1. 安装 Inno Setup 6（含中文语言包 ChineseSimplified.isl）

```

生成的安装程序位于 `packaging\output\催客写作_Trecal_1.0.0_Setup.exe`，
